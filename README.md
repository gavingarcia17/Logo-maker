# Logo-maker

## Description

The SVG Logo Maker is a command-line application that generates SVG logos based on user input. Users can specify the text, text color, shape, and shape color for the logo. This tool helps developers quickly create custom SVG logos for their projects.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/svg-logo-maker.git
    ```
2. Navigate to the project directory:
    ```bash
    cd svg-logo-maker
    ```
3. Install the dependencies:
    ```bash
    npm install
    ```

## Usage

1. Run the application:
    ```bash
    npm start
    ```
2. Answer the prompts to generate your SVG logo.
3. The generated `logo.svg` file will be created in the project directory.
